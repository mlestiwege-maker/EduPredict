# EduPredict Machine Learning Pipeline

This directory contains the machine learning pipeline for student academic performance prediction.

## Structure

- `data/` - Data storage (raw, processed, sample)
- `notebooks/` - Jupyter notebooks for experimentation
- `src/` - Production ML code
  - `preprocessing/` - Data cleaning and validation
  - `features/` - Feature engineering
  - `training/` - Model training and evaluation
  - `explainability/` - Model explanations
- `models/` - Trained model files
- `reports/` - Evaluation reports

## Usage

See the notebooks for experimentation and the src modules for production use.
